## 🛠️ Local Setup

### Prerequisites
- Python 3.10 or higher
- pip
- Git

### Step 1 — Clone the repo
```bash
git clone https://github.com/Priyanshu16705/movie-recommender.git
cd movie-recommender
```

### Step 2 — Create a virtual environment (recommended)
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python -m venv venv
source venv/bin/activate
```

### Step 3 — Install dependencies
```bash
pip install -r requirements.txt
```

### Step 4 — Train the models
```bash
python train.py
```
This will:
- Load and preprocess `data/movies.csv`, `ratings.csv`, `tags.csv`
- Fit TF-IDF vectoriser and cosine similarity matrix
- Train SVD model via Surprise
- Run 5-fold cross-validation (RMSE, MAE, Precision@10, Recall@10)
- Save all artefacts to `models/`

Expected output:
```
=== Loading data ===
  Loaded movies.csv: 500 rows × 3 cols
  Loaded ratings.csv: 50,234 rows × 4 cols
  ...
✅  Training complete!  Run: streamlit run app.py
```

### Step 5 — Launch the app
```bash
streamlit run app.py
```
Then open **http://localhost:8501** in your browser.

## 🧠 How It Works

### A. Content-Based Filtering (`content_based.py`)

1. Each movie's **genres** and **user tags** are concatenated into a `content` string.
2. **TF-IDF Vectorisation** (unigrams + bigrams, English stop-words removed) converts text to a feature matrix.
3. **Cosine Similarity** is computed between every pair of movies → n×n matrix.
4. For a query movie, the top-K rows with highest similarity scores are returned.

```
"Action Adventure | fun classic"  →  TF-IDF vector  →  cosine_sim  →  Top-K
```

### B. Collaborative Filtering (`collaborative_filtering.py`)

1. The user × movie rating matrix is loaded into [Surprise](https://surpriselib.com/).
2. **SVD** (Matrix Factorisation) is trained with 100 latent factors, 20 SGD epochs.
3. For a target user, ratings are predicted for every **unseen** movie.
4. Movies are ranked by predicted rating → Top-K returned.
5. **Cold-start** (< 5 ratings): automatically falls back to content-based.

### C. Hybrid Recommendation (`hybrid_recommender.py`)

```
hybrid_score = α × content_similarity + (1 − α) × normalised_CF_score
```

- Default **α = 0.4** (60% CF, 40% content). Adjust via the sidebar slider.
- Both scores are min-max normalised to [0, 1] before blending.
- Cold-start users get α = 1.0 automatically.

## 📊 Evaluation Metrics

| Metric | Description | Value (synthetic data) |
|--------|-------------|----------------------|
| **RMSE** | Root Mean Squared Error — 5-fold CV on SVD | ~1.49 |
| **MAE** | Mean Absolute Error — 5-fold CV on SVD | ~1.28 |
| **Precision@10** | Fraction of top-10 recs that are relevant (rating ≥ 3.5) | ~0.33 |
| **Recall@10** | Fraction of all relevant movies found in top-10 | ~0.84 |

> **Using real MovieLens data** (100k+ ratings) will significantly improve RMSE/MAE.

## 🌐 Deploy on Streamlit Cloud

1. **Fork / push** this repo to your GitHub account.
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select your repo, branch `main`, and set **Main file** to `app.py`.
4. Under **Advanced settings → Secrets**, add:
   ```toml
   TMDB_API_KEY = "your_tmdb_api_key_here"
   ```
5. Click **Deploy** — done! Your app gets a public URL.

> ⚠️ **Important**: The `models/` folder must be committed (or the app runs `train.py` on startup). Large `.npy` / `.pkl` files are git-ignored by default. See the note below.

### Handling large model files on Streamlit Cloud

Option A — Commit small models only (recommended for this project):
- `movie_df.pkl` and `metrics.json` are committed (< 1 MB each).
- On first launch, `train.py` is called automatically if `sim_matrix.npy` is missing.
- The app detects missing models and shows an error with instructions.

Option B — Use [Git LFS](https://git-lfs.com/) to store large `.npy`/`.pkl` files.

## 🖼️ TMDB Integration

Movie posters and overviews are fetched from [The Movie Database (TMDB)](https://www.themoviedb.org/).

- Get a **free API key** at: https://www.themoviedb.org/settings/api
- Paste it in the sidebar **or** add to Streamlit secrets.
- Without a key: placeholder images are shown — recommendations still work fully.
